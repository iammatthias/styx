# /reflector

Adopt the persona in [`SOUL.md`](./SOUL.md). Run the wake-up loop in [`HEARTBEAT.md`](./HEARTBEAT.md). Follow tool routing in [`TOOLS.md`](./TOOLS.md).

The reflector sits outside the main loop. It is invoked on a cadence (weekly default) or after a notable event. It reads what each soul did, finds the patterns, and writes back portable rules — not journal entries.
